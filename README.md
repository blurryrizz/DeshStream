
# Desh Stream

Collects publicly available live stream links for Bangladeshi television channels in one place, making it easier to discover and access live broadcasts.


## 📺 How to play




### 1. Copy the playlist link

Copy the public M3U playlist URL:

`https://raw.githubusercontent.com/blurryrizz/DeshStream/refs/heads/main/DeshStream.m3u`

### 2. Open VLC

Download and install **VLC Media Player** if you don't already have it.

Open VLC on your computer.

### 3. Open the network stream

From the VLC menu, go to:

**Media → Open Network Stream**

### 4. Paste the playlist URL

Paste the M3U link into the **Network URL** field.

Then click **Play**.

### 5. Choose a channel

If the playlist contains multiple channels, VLC will load the playlist.

Open:

**View → Playlist**

You can then select any available channel and start watching.

---

## 📱 On Android

1. Install a media player that supports M3U playlists.
2. Open the app.
3. Choose **Open Network Stream** or **Add Playlist**.
4. Paste the M3U playlist URL.
5. Load the playlist.
6. Select a channel and start streaming.

## 🍎 On iPhone / iPad

1. Install an M3U-compatible media player.
2. Choose **Add Network Stream** or **Add Playlist**.
3. Paste the M3U URL.
4. Load the playlist.
5. Select a channel to watch.

> **Note:** Channel availability depends on whether the original live stream is online and accessible. This playlist only provides links to the streams; it does not host or rebroadcast the video itself.
